# Journal of Corporate and Financial Laws (JCFL)

> **Published by the Centre for Corporate Law, Governance & Financial Laws (CCLGFL)**  
> *Inaugural Edition (Volume 1 · Issue 1, 2026)*

A complete, production-ready, premium academic law journal website establishing the Journal as a serious, credible, and forward-looking digital platform for scholarship in corporate law, financial law, governance, securities regulation, commercial law, and related disciplines.

---

## 🏛️ Brand & Institutional Identity

- **Primary Publication Name**: *Journal of Corporate and Financial Laws (JCFL)*
- **Institutional Line**: *Centre for Corporate Law, Governance & Financial Laws (CCLGFL)*

- **Paper White (`#FFFFFF`)**: Clean card and reading surfaces.
- **Governance Teal (`#537C78`)**: Academic taxonomy and category badges.
- **Academic Gold (`#B99A5E`)**: Restrained micro-details, volume indicators, and collectible cover accents.

  - *Source Serif 4*: Editorial headlines, publication titles, blockquotes, and volume headers.
  - *Inter*: Interface UI, filters, navigation, labels, and forms.

## ⚡ Interactive Features

1. **Global Command Palette (⌘K / Ctrl+K)**: Instant fuzzy search across articles, authors, taxonomy domains, and static pages with keyboard navigation (`↑`/`↓`/`Enter`/`Esc`).
2. **Academic Citation Generator**: 1-click citation generation in **Bluebook (21st Ed.)**, **OSCOLA (4th Ed.)**, **APA (7th Ed.)**, **MLA (9th Ed.)**, **Chicago (17th Ed.)**, and **BibTeX**.
3. **Interactive Bidirectional Footnotes**: Hover tooltip previews for numbered superscripts, smooth anchor scrolling to references, and `↩` back-jumps to exact reading position.
4. **Interactive Author Submission Checklist**: 8-point interactive pre-submission verification checklist with live progress tracking and confetti celebration upon full compliance.
5. **Collectible 3D Issue Cover**: Subtle CSS 3D perspective tilt mockup featuring the official CCLGFL seal.
6. **Embedded PDF Viewer Modal**: Print-ready academic document layout and PDF access options.

## 🛠️ Technology Stack

- **Framework**: Next.js 16 (App Router, SSG/SSR)
- **Language**: TypeScript
- **Styling**: Tailwind CSS v4 + Vanilla CSS Design Tokens
- **Icons**: Lucide React
- **Animations & Effects**: HTML5 Canvas 60fps Nodal Engine, CSS 3D Perspective Transforms, Canvas Confetti

## 🚀 Getting Started

### 1. Install Dependencies
```bash
npm install
```

### 2. Run Local Development Server
```bash
npm run dev
```
Open [http://localhost:3000](http://localhost:3000) in your browser.

### 3. Build Production Bundle
```bash
npm run build
```
